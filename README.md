# meiguodizhionline

美国地址在线，一个可直接部署到 Cloudflare Pages 的静态工具站。

## 页面

- `/` 中文美国地址生成器
- `/en/` 英文美国地址生成器
- `/tax-free-address/` 美国免税州地址生成器
- `/blog/` 博客入口
- `/about/`、`/privacy/`、`/terms/`、`/contact/`

## Cloudflare Pages 部署

Build command 留空。

Build output directory 填：

```text
/
```

如果 Cloudflare Pages 要求输出目录，填：

```text
.
```
